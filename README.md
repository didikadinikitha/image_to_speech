# image_to_speech
Built an Image-to-Speech Generative AI system using Gemini Vision that analyzes images and produces spoken descriptions for accessibility applications. Integrated AI-based image understanding with real-time audio generation.
# Image to Speech using Gemini

This project converts images into speech using Google's Gemini multimodal model.

##  Features
- Image understanding using Gemini Vision
- AI-generated image description
- Text-to-Speech conversion
- Multi-language audio output
- Download generated speech

## Tech Stack
- Gemini 1.5 Flash
- Streamlit
- Python
- gTTS
- Pillow
